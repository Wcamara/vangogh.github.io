PORTFÓLIO PENTEST / CTF

Arquivos:
- index.html: conteúdo do site
- style.css: visual e responsividade
- script.js: menu mobile e ano automático

COMO ABRIR
1. Extraia a pasta.
2. Abra o arquivo index.html no navegador.

O QUE EDITAR
- Nome, descrição e habilidades no index.html.
- Troque os links com href="#" pelos seus links reais.
- Troque seuemail@exemplo.com pelo seu e-mail.
- Para adicionar um novo CTF, copie um bloco <article class="project-card">.

COMO PUBLICAR GRÁTIS
Você pode enviar a pasta para GitHub Pages, Netlify ou Vercel.
